# Tyrol region enrichment

## What changed

Enriched the Tyrol region description on Austria's existing `/luxury-villas/austria/` page in
`src/countries.py`. The description previously read:

> "Alpine valleys, mountain huts and ski resorts, with chalets for summer and winter."

Added a second sentence naming three specific, bookable circular walks from Seefeld itself
(confirmed by Seefeld's own tourism site and Komoot, per the topic-map entry):

- A forest walk to the historic inn at Triendlsäge (Gasthof Triendlsäge)
- A longer walk out to the Wildmoosalm alpine hut
- The Gschwandtkopf round tour for valley views

## Why

Per `research/topic-map.md`'s "Tyrol: Seefeld's Circular Walk to the Historic Inn at
Triendlsäge" entry: chalet-rental listings for Seefeld (Mountains Chalets, Löwen Chalets, a
5-bedroom Kranebitten/Sellrain property) describe bedroom count, sauna and ski-area proximity
only, naming none of these specific walks or huts. Austria's existing Tyrol description named no
village, trail or hut — the same generic-description gap already closed for the Salzkammergut
and Wachau Valley on this same Austria page. This closes it for Tyrol using the same "step
straight onto its own walks from the village" framing (a group based in Seefeld, not day-tripping
in from elsewhere) already established in the Salzkammergut and Wachau entries right above it.
